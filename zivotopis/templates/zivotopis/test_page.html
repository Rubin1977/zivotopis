            📂 Projekt: Životopis –> vývoj + testovanie
        

        

            
Popis: Osobná stránka životopisu s dôrazom na čisté UI/UX, responzívnosť a jasnú navigáciu. Tento zápis dokumentuje moju prácu ako autor (vývoj) aj tester (QA). Okrem samotného vývoja obsahuje aj automatické testy v Djangu, ktoré overujú:

            
    
                
  • funkčnosť aplikácie a autentifikáciu používateľov,
    • 
                
  • správne spracovanie požiadaviek a validáciu formulárov,
    • 
                
  • routing URL a logiku modelov,
    • 
                
  • REST API bezpečnosť, kde verejné endpointy sú read-only, write operácie sú viazané na autentifikáciu a formulárové endpointy neumožňujú čítanie dát.
    • 
            


            

            

                
    
                
  • Stack: Django, HTML/CSS, PythonAnywhere
    • 
                
  • 
                    Endpointy: 
                    /zivo/, 
                    /en/zivo/, 
                    /email/
                
    • 
                

            


            

                
    
                
  • Moja rola: Vývoj (Django + UI + REST API návrh), QA (SOAPUI + Selenium), dokumentácia testovacích prípadov a roadmapy
    • 
                
  • Ciele kvality: Dostupnosť (HTTP 200 OK), správny obsah, funkčné linky, EN/SK lokalizácia, bezpečné REST API (permissions, read-only/write operations, validácia formulárov)

Roadmapa učenia

            
    
                
  1. Týždeň 1: SOAPUI základy – REST/GET požiadavky, status kódy, základné Assertions (Contains/Not Contains), prvé Test Suites Splnené ✅
    2. 
                
  2. Týždeň 2: SOAPUI – SOAP/WSDL operácie, XPath Match, Property Transfer medzi testami, základné Groovy skripty na dynamické assertions Prebieha
    3. 
                
  3. Týždeň 3: Selenium WebDriver – základné UI testy (navigácia, kliknutia, vyhľadávanie elementov), testovanie formulárov, validácia chýb, Page Object Pattern 📌 Plán
    4. 
                
  4. Týždeň 4: Pokročilé QA – kombinácia SOAPUI + Selenium (API + UI scenáre), Mock Services v SOAPUI, reportovanie výsledkov, príprava portfólia na GitHub 📌 Plán
    5. 
            


            
Poznámky

            
    
                
  • Groovy vs Python – interpolácia reťazcov, logovanie, parsovanie XML
    • 
                
  • CSRF – netýka sa GET; pri POST treba token + cookies
    • 
                
  • Assertions – Contains/Not Contains pre HTML; XPath pre SOAP XML
    •                 
                
  • Django TestCase – integračné testy simulujú reálne požiadavky cez testovacieho klienta, overujú redirecty a stav databázy
    • 
                
  • Django SimpleTestCase – unit testy URL routingu, kontrola mapovania názvov na view funkcie
    • 
                
  • Kombinácia SOAPUI + Selenium – umožňuje end-to-end scenáre, kde sa testuje API aj UI vrstva naraz
    • 
                
  • Mock Services – využitie v SOAPUI na simuláciu odpovedí API, vhodné pri integračných testoch
